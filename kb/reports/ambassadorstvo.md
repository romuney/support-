# Амбассадорство сотрудников

## Назначение
Отчёт об участии сотрудников в программе «Амбассадоры»: затраченное время
на активности, частота участия и доля участвующих от численности.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/employee_ambassadorship/
(Data Detective → Каталог → Амбассадорство сотрудников, отчёт
`ambassadorstvo-vneproektnye-aktivnosti-sotrudnikov`).

## Какие метрики внутри
—

## На каких данных построен
Внепроектные активности сотрудников по программе «Амбассадоры», мастер-системы
«Амбассадоры · Т-Гейм · PeopleHub». В DD к отчёту привязан ноутбук Helicopter
(объект 1291904).

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
Данные участия в программе — чувствительные; RLS для сокрытия чувствительных
данных.

## Кому доступен
Доступ по AD-группе `tableau-all` (атрибут отчёта в DD). RLS для сокрытия
чувствительных данных. Владелец отчёта — онлайн из Data Detective
(объект `ambassadorstvo-vneproektnye-aktivnosti-sotrudnikov`);
канал поддержки — `~hr-report-ask`.
