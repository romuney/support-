# HR Executive Report

## Назначение
Отчёт для анализа динамики ключевых HR-метрик: численность, найм, отток,
переводы, текучесть. Отвечает на вопросы «как менялась численность группы
компаний», «за счёт каких метрик изменилась численность», «статистика найма
и оттока», «чему равна текучесть».

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/hr-executive-report
(Data Detective → Каталог → HR Executive Report, отчёт 1845).

## Какие метрики внутри
`m-active-headcount`, `m-legal-headcount`, `m-hiring`, `m-turnover`.
Разделы: Динамика численности, Детализация метрик (Движение персонала,
Перевод−/Перевод+), Аналитика найма, Аналитика оттока, Соцдем-факторы,
HQ Светофор.

## На каких данных построен
`t-emp-structure`, `t-legal-position-change`, `t-dismissal-reason`
(+ служебные витрины-источники, которых пока нет в реестре:
`management_position_attr_chng`, `mdm_employee_common_attr_change_d`,
`mdm_employee_t_education`, `regrettable_n_non_regrettable_base`,
`functional_role_d_br`).

## Срез и период обновления
Динамика с настраиваемой гранулярностью дат (месяц/квартал/год). Данные на конец
дня, обновление ежедневно. По умолчанию отчёт отфильтрован по активной
численности; юридическая — переключением фильтра.

## Ограничения
- Метрики переводов пересчитываются в зависимости от выбранных фильтров —
  логика расчёта в карточке метрики.
- Детальные списки на вкладках Перевод−/Перевод+ ограничены 5 000 строк —
  использовать фильтры, иначе строки теряются.
- Метрика «на вчера» отображается только на линейном графике, для интерпретации
  YTD-показателей не используется.
- HQ Светофор: метрика и цветовая индикация требуют минимальной средней
  численности в последнем выбранном периоде — 100 сотрудников для Total
  и Non-Regrettable текучести, 50 для Regrettable. Ниже порога метрика
  не отображается, но абсолютное число уволившихся с начала года остаётся
  видимым.

## HQ Светофор: цели и зоны

Сводка текучести для активной численности HQ, целевые значения — годовые цели:

| метрика | цель |
|---|---|
| Total текучесть | 15% |
| Total IT текучесть | 12% |
| Non-Regrettable текучесть | 5–15% |
| Regrettable текучесть | 4% |

Зелёная зона — метрика в пределах целевого диапазона, красная — превышает цель.
Значения карточек считаются только по созревшим периодам (неполные исключаются).
Пороги отображения — см. «Ограничения».

## Кому доступен
Сотрудникам с персональной зоной видимости (RLS). Владелец и канал поддержки —
онлайн из Data Detective (атрибуты отчёта); канал — `~hr-report-ask`.
