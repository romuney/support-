# Календарь присутствия сотрудников

## Назначение
Отчёт по табелю сотрудника: расписание присутствия и отсутствия на каждый день.
Показывает, как сотрудник отработал день — по типам из табеля посещаемости.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/19710
(Data Detective → Каталог → Календарь присутствия сотрудников, отчёт 2529).

## Какие метрики внутри
—

## На каких данных построен
`t-attendance`

## Срез и период обновления
Подневная детализация (сотрудник × день). Актуальность — как у источника табеля:
приоритет ТВФМ — данные до двух недель, 1C — старше двух недель.

## Ограничения
Отчёт показывает факт присутствия/отсутствия по типу, но не причину: диагнозов
в данных нет (есть тип отсутствия, а не его причина). Разрез по конкретным людям
чувствителен и требует согласования доступа.

## Кому доступен
Доступ через Data Detective. В отчёте настроена RLS для сокрытия чувствительных
данных в зависимости от прав пользователя.
