# Онлайн-встречи сотрудников HQ

## Назначение
Отчёт для руководителей с детализацией загруженности встречами в Толке
сотрудников на уровне −1, −2.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/25690/
(Data Detective → Каталог → Онлайн-встречи сотрудников HQ, отчёт 2275).

## Какие метрики внутри
—

## На каких данных построен
Онлайн-встречи в Толке. По умолчанию отображаются встречи с 3+ участниками
и наличием логов Толка; связанные таблицы в DD не зафиксированы
(связь INCLUDES пуста).

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
По умолчанию — только встречи с 3+ участниками и наличием логов; остальные
данные добавляются фильтрами. Отчёт отражает загруженность встречами
на уровнях −1, −2, а не всю активность руководителя.

## Кому доступен
RLS для сокрытия чувствительных данных. Владелец отчёта — онлайн из Data Detective
(объект 2275).
