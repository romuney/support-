# Как определить декрет сотрудников и декрет с продолжением работы

## Вопрос дословно

> 1) В какой таблице смотреть декрет сотрудников? 2) Как определить декрет с продолжением работы?

## Ответ

**Где смотреть:** витрина `prod_v_emart.legal_position_d`, поле `employee_status_desc = 'В декрете'`.

**Как определить декрет с продолжением работы:** если у сотрудницы штатная позиция в декрете + активная ГПХ-позиция — она продолжает работать.

**Нюанс:**
- с отпуском по уходу можно работать на штатной позиции
- с больничным по БиР — только на ГПХ
