# hrmart.legal_position_dismissal_reason

## Что описывает

Причина увольнения сотрудника **со слов самого сотрудника** (комментарий
при увольнении) — не путать с формальным кодом причины увольнения в
кадровой системе, если такой уже есть в другой витрине.

## Гранулярность строки

Не подтверждено — уточнить у владельца витрины.

## Первичный ключ

Не подтверждено — уточнить у владельца витрины.

## Ключи для связывания

| С чем | По каким полям |
|---|---|
| `t-emp-structure` | `legal_position_rk = legal_position_rk` **и** `legal_fire_dt = fire_dt` |

Оба условия обязательны: связка по одному `legal_position_rk` без даты
увольнения может задвоить строки при нескольких оформлениях на одной
юридической позиции.

## Срез атрибутов

Не заполнено — уточнить у владельца витрины.

## Период и глубина истории

Не заполнено — уточнить у владельца витрины.

## Как обновляется

Не заполнено — уточнить у владельца витрины.

## Категорически нельзя

1. **Джойнить только по `legal_position_rk`, без `legal_fire_dt = fire_dt`** —
   риск задвоения при повторных оформлениях.
2. **Путать с формальной причиной увольнения из кадровой системы** — это
   текст со слов сотрудника, а не официальный код; для отчётности по
   текучести (`m-turnover`) не заменяет формальную причину.

## Персональные данные

Комментарий сотрудника при увольнении может содержать чувствительные
детали (личные обстоятельства, конфликты). В выгрузки не попадает
дословно, только агрегированная категория, если она есть в поле.

## Связанные сущности

`t-emp-structure`, `t-legal-position`, `m-turnover`
