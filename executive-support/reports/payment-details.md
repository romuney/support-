# Платежные реквизиты по юридическим позициям

## Назначение
Отчёт по всем юридическим позициям и наличию платежных документов сотрудников
и исполнителей.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/payments_requsites/
(Data Detective → Каталог → Платежные реквизиты по юридическим позициям,
отчёт 2330).

## Какие метрики внутри
—

## На каких данных построен
Данные по юридическим позициям и наличию платежных документов сотрудников
и исполнителей, мастер-система PeopleHub. В DD к отчёту привязан ноутбук
Helicopter (объект 922754).

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
Платежные реквизиты — чувствительные данные; RLS для сокрытия чувствительных
данных.

## Кому доступен
Доступ по AD-группе `collection_head_sector_wo_payments`. RLS для сокрытия
чувствительных данных. Владелец отчёта — онлайн из Data Detective (объект 2330).
