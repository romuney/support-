# Выявление сотрудников с низкой посещаемостью при зафиксированном рабочем месте

## Вопрос дословно

> **Утилизация рабочих мест:** сотрудники с низким % посещаемости, но есть фикс место. Данные: логин, место, % посещаемости

## Ответ

Использовать отчет «[Посещаемость и бронирование офисов](https://proteus.tcsbank.ru/superset/dashboard/p/Jw3XZwBd5Ye/)».

Для автоматизации можно завести задачу на выгрузку данных по утилизации рабочих мест.

## Чего не хватило

Не восстановить из выгрузки.
