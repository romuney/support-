# Почему у сотрудника не указан Siebel ID и можно ли поправить

## Вопрос дословно

> Почему у сотрудника (MID 855859) не указан зибель ID и можно ли поправить?

## Ответ

Связь сотрудник-клиент не проставляется при отсутствии совпадения ФИО + телефон.

**Частая ситуация для:**
- ТЦР из РБ
- ТЦР из Армении
- ТЦР из Казахстана
- ТЦР из Узбекистана

**Решение:** выровнять номер телефона через поддержку Майти или региональные кадры.

## Чего не хватило

Не восстановить из выгрузки.
