# Юридические позиции сотрудника за период

## Назначение
Отчёт со списками всех сотрудников группы компаний с атрибутами юридической
структуры и всеми юридическими позициями за период, включая совместительство.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/4823/
(Data Detective → Каталог → Юридические позиции сотрудника за период, отчёт 1801).

## Какие метрики внутри
`m-legal-headcount`

## На каких данных построен
`t-legal-position`

## Срез и период обновления
Срез за период по юридическим позициям: основное оформление, совместительство,
ГПХ. Актуальность — как у витрины юридических позиций.

## Ограничения
Один сотрудник может иметь несколько юридических позиций (включая
совместительство) — при подсчёте людей нужен distinct по сотруднику, а не `count(*)`.
Для управленческой отчётности использовать не следует — см. `rc-structure-choice`.

## Кому доступен
Доступ через Data Detective. В отчёте настроена RLS для сокрытия чувствительных
данных в зависимости от прав пользователя.
