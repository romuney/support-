# HR Executive — Детальные списки

## Назначение
Отчёт-трансформер для формирования детальных списков сотрудников с настраиваемым
набором атрибутов. Решает задачи выгрузки атрибутов по своей команде или группе
сотрудников и обогащения данных дополнительными атрибутами: кадровые мероприятия,
отчётность по структуре подразделения, проверка контактов и атрибутов.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/hr-executive-detail-employee
(Data Detective → Каталог → HR Executive — Детальные списки, отчёт 1728).

## На каких данных построен
`t-emp-structure`, `t-summary-evaluation` (+ мост `functional_role_d_br` —
в реестре пока нет).

## Срез и период обновления
Актуальный срез на конец дня; «Последний день» = предыдущий рабочий день.
Обновление ежедневно.

## Ограничения
- Максимальный объём полной выгрузки — 150 000 строк. Вкладки: «Выгрузка 1000
  строк» (лимит 1 000), «Все строки» тремя частями по 50 000, «Выгрузка КП»
  (лимит 100 000).
- Часть атрибутов — персональные данные; пересылка по незащищённым каналам
  запрещена. Поля, требующие согласования, остаются в составе и помечаются 🔒 —
  см. `kb/process/export-playbook.md`.
- В отчёте персональная зона видимости (RLS): каждый пользователь видит данные
  только по своей зоне ответственности.

## Кому доступен
Сотрудникам с персональной зоной видимости (RLS). Владелец и канал поддержки —
онлайн из Data Detective (атрибуты отчёта); канал — `~hr-report-ask`.
