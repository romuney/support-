# Центр развития Аватар

## Назначение
Отчёт по количеству сотрудников, которые прошли программу «Аватар».

## Где открыть
Tableau → https://tableau.tcsbank.ru/#/workbooks/34040/views
(Data Detective → Каталог → Отчет. Центр развития Аватар, отчёт 1946).

## Какие метрики внутри
—

## На каких данных построен
`usr_cross_data.upgrade_evaluation_tqm` — данные программы развития (мастер-система
TQM). В DD к отчёту привязан ноутбук Helicopter (объект 778428).

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
Отчёт показывает, сколько сотрудников прошли программу, — не покрывает
результаты или качество прохождения.

## Кому доступен
RLS для сокрытия чувствительных данных. Владелец отчёта — онлайн из Data Detective
(объект 1946).
