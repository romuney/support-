# Поддержка программы Приведи друга

## Назначение
Отчёт содержит данные по поступившим в чат на MyT и в Forge запросам
в поддержку программы «Приведи друга». По запросам из Forge представлена
детализированная аналитика по производительности и соблюдению SLA по срокам
обработки.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/14586
(Data Detective → Каталог → Поддержка программы Приведи друга, отчёт 2048).

## На каких данных построен
Данные по запросам в поддержку программы «Приведи друга» из чата на MyT
и из Forge. В DD к отчёту привязан ноутбук Helicopter (объект 846491).

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
Аналитика SLA по срокам обработки доступна по запросам из Forge; по запросам
из чата MyT — только данные о поступивших обращениях.

## Кому доступен
Доступ по AD-группам: `technology-assessment-leads`, `bi_analyst_lead`.
RLS для сокрытия чувствительных данных. Владелец отчёта — онлайн из Data Detective
(объект 2048).
