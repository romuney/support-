# Детализация дневной активности

## Назначение
Отчёт для приблизительного анализа активности сотрудника в нескольких скоупах.

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/employee-activity-detail/
(Data Detective → Каталог → Детализация дневной активности, отчёт 2115).

## Какие метрики внутри
—

## На каких данных построен
`sse_cross_perf.employee_activity_detail` — витрина детализации дневной активности
по сотрудникам.

## Срез и период обновления
Обновление ежедневно. Статус отчёта в DD — «Активен».

## Ограничения
Анализ приблизительный: отчёт предназначен для обзора активности в нескольких
скоупах, а не как точный учёт рабочего времени.

## Кому доступен
RLS для сокрытия чувствительных данных. Владелец отчёта — онлайн из Data Detective
(объект 2115); канал поддержки — `employee-work-monitoring-report`.
