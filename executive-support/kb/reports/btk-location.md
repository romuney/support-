# БТК. Местоположение и заявления для возврата почтой РФ

## Назначение
Отчёт с данными по местоположению БТК (бумажных трудовых книжек) и со списком
активных заявлений на возврат бумажных трудовых книжек почтой РФ — при увольнении
и при переходе на электронную трудовую книжку (ЭТК).

## Где открыть
Proteus → https://proteus.tcsbank.ru/superset/dashboard/15657/
(Data Detective → Каталог → БТК. Местоположение и заявления для возврата почтой РФ,
отчёт 2088).

## На каких данных построен
Заявления из EDMS (ЭДО): `sdp_edms_statement.statement` — таблица заявлений
сотрудников. В реестре есть `t-statement-field` (поля заявлений), но отчёт читает
родительскую таблицу заявлений `statement`, а не `statement_field`.

## Срез и период обновления
Обновление несколько раз в сутки. Статус отчёта в DD — «Активен».

## Ограничения
Данные заявлений — чувствительные персональные данные; передача по незащищённым
каналам запрещена (см. [экспорт-плейбук](../process/export-playbook.md)).

## Кому доступен
Доступ через Data Detective по AD-группам: `tcr_hr`, `kadry_ooo`, `hr2`.
Владелец и заказчик отчёта — онлайн из Data Detective (атрибуты отчёта, объект 2088);
канал поддержки — `~hr-report-ask`.
