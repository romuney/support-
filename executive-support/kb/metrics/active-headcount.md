# Активная численность

## Определение одной фразой

Количество сотрудников, работающих в компании на дату и не уволенных, —
управленческий взгляд на численность.

## Формула

```sql
active_employee_flg = 1 and company_fire_flg = 0
```

Оба условия обязательны. Флаг `company_fire_flg`, а не `fire_flg`.

## Что в числителе и знаменателе

Метрика абсолютная: `count(mdm_employee_rk)` по условию выше.

## Гранулярность и период

Считается на дату. Для актуального значения — `last_day_flg = 1`.
Для среза на конкретную дату — `business_dt = date 'ГГГГ-ММ-ДД'`.
Для динамики — группировка по `business_dt` без `last_day_flg`.

## Где считается

`t-emp-structure` (`prod_v_emart.mdm_employee_structure_d`).

Базовый запрос:

```sql
select
    m.business_dt  -- отчётная дата
    , count(m.mdm_employee_rk) as active_headcount  -- численность
from prod_v_emart.mdm_employee_structure_d m
where m.active_employee_flg = 1  -- активный
  and m.company_fire_flg = 0  -- не уволен
group by 1
order by 1;
```

## Категории численности

| Категория | Критерии |
|---|---|
| Активная | `active_employee_flg = 1 and company_fire_flg = 0` |
| Стажёры | `active_type_nm = 'Стажеры'` |
| Подрядчики | `active_type_nm = 'Подрядчики'` |
| Неактивная | `active_type_nm in ('Декрет', 'Прогульщики', 'Мобилизованные')` или `legal_unit_nm ilike '%Разметчики%'` или `legal_unit_nm ilike '%Учебная группа%'` |

Все категории считаются по одному полю — `active_type_nm`, и написание значений
берётся из его перечня в `t-emp-structure`. Раньше в трёх строках этой таблицы
стояли `status_nm` и `employment_type_nm` со значениями в единственном числе
(`'Декрет', 'Прогульщик', 'Мобилизованный'`). Ни одно из этих двух полей
не встречается больше нигде в базе, а те же категории пятью другими статьями
определяются через `active_type_nm` — где значения записаны во множественном
(`'Прогульщики'`, `'Мобилизованные'`). Промах здесь тихий в обе стороны:
неверное имя поля роняет запрос громко, а неверное написание значения даёт
**ноль строк без ошибки**, и «в этой категории никого нет» читается как факт.
Если `status_nm` и `employment_type_nm` в витрине всё же есть и нужны — вернуть
их сюда можно только вместе со сверкой значений по каталогу.

## Чем НЕ является

Это **не** юридическая численность (`m-legal-headcount`). Цифры расходятся
закономерно: разные флаги и разный смысл. Для расчётов основной считается
юридическая численность.

Где активная численность применяется, а где нет:

| Подходит | Не подходит |
|---|---|
| Анализ оттока и текучести | Операционные рассылки |
| Сравнение подразделений по HR-метрикам | Учёт посещения офисов |
| Отчётность для руководства | Выдача подарков |

## Частые расхождения

**«На сейчас» посчитали через `business_dt = current_date - 1` и получили ноль
или заниженное число.** Витрина обновляется с задержкой. Актуальность —
только `last_day_flg = 1`.

**Численность за период не сходится.** `last_day_flg = 1` фильтрует один день.
Для периода нужен диапазон по `business_dt`.
