# Словарь синонимов: слово заказчика → поле

## Какую задачу решает

Заказчик говорит «стрим», «HQ», «текучка», «сколько людей». Таблица ниже
переводит это в имена полей и фильтры. Точное написание значений всё равно
подтверждается через `select distinct` — см. `kb/process/sql-conventions.md`.

## Какие таблицы участвуют

`t-emp-structure` — если не указано иное.

## Словарь

| Заказчик говорит | Поле или фильтр |
|---|---|
| стрим, направление | `emp_stream_desc` |
| специализация | `emp_specialization_desc` |
| HQ / Line / Support | `emp_specialization_oper_code` |
| IT / Non-IT / Digital | `emp_specialization_it_code` |
| активная численность, HC, headcount, сколько людей | `active_employee_flg = 1 and company_fire_flg = 0`, см. `m-active-headcount` |
| юридическая численность, оформленные, трудоустроенные | `legal_employee_flg = 1`, см. `m-legal-headcount` |
| грейд | `emp_grade_desc` |
| FTE по продукту, аллокация | `sum(allocation_prt)` в `functional_role_d`, см. `m-fte-product` |
| руководитель в оргструктуре | уточнить: `management_head_flg` или `legal_head_flg` |
| руководитель, тимлид в продукте | уточнить: `business_head_flg` / `technical_head_flg` / `service_head_flg` |
| управленческое подразделение, команда, департамент | `lvl{N}_mapped_management_unit_nm`, N = 3..13 |
| структурное подразделение, юр. единица | `lvl{N}_legal_unit_nm` в `t-legal-position`, см. `rc-structure-choice` |
| стаж в компании | `current_date - company_hire_dt` |
| стаж в подразделении, специализации, должности, грейде, роли | gaps & islands, см. `rc-attribute-tenure` |
| текучка, текучесть, отток | см. `m-turnover` |
| найм, приёмы, набор | см. `m-hiring` |
| больничный, отсутствие, неявка | `attendance_type_desc` в `t-attendance` |
| отработанные дни | `attendance_type_desc = 'Рабочий день'` в `t-attendance` |
| табель, посещаемость | `t-attendance` |
| образование, диплом, учёба | `education_level_nm`, `education_status_nm` в `t-education` |
| высшее образование, бакалавриат, магистратура | `education_level_nm ilike '%высш%'` |
| студент, учится, академ | `education_status_nm ilike '%Студент%'` или `ilike '%академ%'` |
| учебное заведение, ВУЗ | `education_institution_nm` |
| специальность по образованию | `education_spec_nm` |
| квалификация по диплому | `qualification_nm` |
| год окончания | `graduation_year` |
| скан диплома | `scan_flg = 1` |
| стажёр, стажировка, интерн | `active_type_nm = 'Стажеры'` — только это поле |

## Значения `active_type_nm`

13 значений. Если заказчик употребил любое из правых формулировок — фильтр
по `active_type_nm`.

| Значение в поле | Как говорят |
|---|---|
| `Активная` | активные сотрудники, действующий персонал |
| `Стажеры` | стажёры, стажировка, интерны, участники программы стажировки |
| `Декрет` | декрет, отпуск по уходу за ребёнком |
| `Подрядчики` | подрядчики, контракторы, внешние исполнители |
| `Мобилизованные` | мобилизованные, сотрудники по мобилизации |
| `Прогульщики` | прогульщики, неявки по дисциплине |
| `На оформлении` | оформление, трудоустройство, кандидаты на оформлении |
| `Кандидаты в учебных юнитах` | кандидаты, учебные юниты, стажёры-кандидаты |
| `POS-агент` | POS-агенты, агенты на точках, полевые агенты |
| `Амбассадор` | амбассадоры, бренд-амбассадоры, евангелисты |
| `Автор стратегий` | авторы стратегий, стратегические консультанты |
| `Клексы` | клексы, Kleksy |
| `Разовые услуги` | разовые услуги, разовые работы, временные услуги |

## Чего избегать

1. **Определять стажёров через `position_nm`, `legal_unit_nm` или `grade`.**
   Только `active_type_nm = 'Стажеры'`.
2. **Использовать значение из словаря без `select distinct`.** Словарь даёт
   имя поля, а не гарантию написания значения.
3. **Угадывать, какой из флагов руководителя нужен.** Их шесть — при отсутствии
   уточнения задаётся один вопрос.

## Как проверить результат

Значение из фильтра встречается в результате `select distinct` по этому полю.
Пустая выборка при непустом фильтре — почти всегда неточное написание значения,
а не отсутствие данных.
