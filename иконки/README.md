# Эмодзи-пак бота поддержки

Реакции и иконки на базе основной картинки бота (`bulli-ref.png`).
Здесь лежат **задания для Nano Banana** и скрипты нарезки. Сами PNG/GIF
кладутся в `out/` и оттуда заливаются в Mattermost.

## Порядок работы

1. Отдать Nano Banana задание из `prompt-stickers.md`, приложив
   `bulli-ref.png`. **По одному стикеру за прогон**, а не листом: первая
   попытка листом снесла стиль — пришёл плоский рисунок с фактурой бумаги
   вместо 3D-рендера. Разбор — в самом файле. **Просить максимальное
   разрешение и PNG**, не JPEG: JPEG мылит границу силуэта, и вырезание
   фона даёт кайму.
2. Отдать задание из `prompt-typing-gif.md` — один лист 3×3 = 9 кадров.
3. Прислать полученные листы сюда. Нарезка и сборка:

```
# по одному стикеру
python3 slice_grid.py bulli_yes.png --cols 1 --rows 1 --names bulli_yes --out out/
# если всё же вышло листом 3x3
python3 slice_grid.py sheet-a.png --names names-a.txt --out out/
# анимация — всегда листом, иначе кадры не совпадут по камере
python3 make_gif.py typing-sheet.png --out out/bulli_typing.gif --ms 80
```

4. Залить в Mattermost: **Main menu → Custom Emoji → Add Custom Emoji**.

## Требования Mattermost

| | |
|---|---|
| Размер | до 128×128 px, файл до 1 МБ |
| Формат | PNG (статика), GIF (анимация) |
| Имя | строчные латиница, цифры, `-` и `_` |

## Фон прозрачный, а не белый

Соблазн сгенерировать сразу на белом — интерфейс Тайма белый, и белое
на белом сойдётся. Не сойдётся в трёх местах, и первое из них главное:

| где | что будет с белым фоном |
|---|---|
| **плашка реакции** | она рисуется на тонированном фоне — белый квадрат виден коробкой даже на светлой теме |
| тёмная тема | её выбирает сам сотрудник, и там белый прямоугольник вокруг персонажа |
| наведение на сообщение, подсветка поиска, упоминание | строка подсвечивается, фон эмодзи — нет |

Прозрачный PNG на белой теме и есть «белое на белом», а в остальных трёх
случаях он единственный, который работает. Плашка реакции решает: именно
в ней эмодзи и живёт.

Генерировать при этом надо на СЕРОМ, а не на белом или прозрачном:
шерсть бульдожки кремовая, почти белая, и заливка с белого фона протекла бы
внутрь персонажа. Прозрачный фон Nano Banana не отдаёт вовсе.

Фон снимается заливкой от краёв кадра, поэтому **никакой обводки вокруг
персонажа не нужно**: серый фон отделяется от кремовой шерсти сам, без каймы
на тёмной теме — проверено прогоном. Белая обводка стояла в первой версии
промпта и оказалась одной из причин слома стиля.

**Заливать уже в 128×128.** Больший файл сервер пережмёт сам, и у анимации
это чаще всего означает потерянные кадры или испорченную прозрачность.
Скрипты отдают ровно 128×128 с альфой.

## Состав пака

Имена — с префиксом `bulli_`, чтобы в списке эмодзи они лежали вместе
и не конфликтовали со стандартными.

### Пачка A — процесс обращения

| эмодзи | состояние | где применяется |
|---|---|---|
| `bulli_typing` | **GIF**: стучит лапами по клавиатуре | взято в работу / бот думает — ставится сразу на обращение и в личке |
| `bulli_ready` | «ответ готов», гордая поза | снимается `bulli_typing`, ставится это |
| `bulli_yes` | палец вверх, подмигивает | высокая уверенность |
| `bulli_hmm` | пожимает плечами | средняя уверенность |
| `bulli_noidea` | лапы разведены, вопрос | `нет ответа` |
| `bulli_done` | зелёная галка | решено (замена `done_checkmark`) |
| `bulli_fail` | красный крест | закрыто нерешённым (замена `im_red_cross`) |
| `bulli_search` | лупа | пошёл в каталог DD |
| `bulli_lock` | замок | согласование ИБ / закрытые поля |
| `bulli_expert` | указывает лапой, стрелка | сработал маршрут из таблицы «Маршруты» |

### Пачка B — тематические и человеческие

| эмодзи | |
|---|---|
| `bulli_export` | выгрузка, держит таблицу |
| `bulli_report` | отчёт, столбчатый график |
| `bulli_broken` | поломка бота (строка `🚩` джуну) |
| `bulli_hi` | машет лапой — приветствие в личке |
| `bulli_wait` | ждёт с кружкой — обращение в очереди |
| `bulli_facepalm` | фейспалм |
| `bulli_thanks` | обнимает сердце |
| `bulli_nothing` | пустая коробка — «такого у нас нет вовсе» |
| `bulli_idea` | лампочка — есть готовый отчёт, можно самому |

`loading`, `done_checkmark`, `im_red_cross` в `telemetry/build_telemetry_flows.py`
**трогать при заливке не надо**: словарь `EMOJI` привязан к именам, а не
к картинкам. Переезд на `bulli_*` — отдельная правка сборщика и витрины,
и делать её надо одним коммитом с обоими файлами, иначе разрез по реакциям
разъедется молча.
